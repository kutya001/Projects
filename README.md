## 📌 О проекте

**Projects SPA** — это полноценная корпоративная система управления проектами, задачами и запросами на изменения (Change Requests). Платформа сочетает молниеносную скорость работы на чистом JavaScript (Zero-Build Vanilla JS) с мощным асинхронным бэкендом на Python и надежной базой данных SQLite (WAL-режим), упаковываясь в один автономный переносимый `.exe` файл.

---

## 🌟 Ключевые возможности

### 1. Архитектура и хранение данных
- **Автономный Windows EXE**: Приложение компилируется в единый переносимый файл `ProjectsSPA.exe` с автозапуском локального сервера и браузера.
- **Асинхронная база SQLite (WAL Mode)**: Многопользовательский доступ с защитой от блокировок (`PRAGMA journal_mode=WAL`, `busy_timeout=5000`).
- **Синхронизация в реальном времени (WebSocket)**: Моментальное обновление данных на всех подключенных устройствах и вкладках без перезагрузки страницы.
- **Двухуровневое резервное копирование**: Автосохранение через *File System Access API* в локальный `.json` файл и ручной экспорт/импорт всей базы данных.

### 2. Модули управления
- 📁 **Проекты**: Контроль сроков, этапов разработки, бюджета, прогресса и ответственных лиц.
- 📋 **Задачи**: Детализация проектной работы, привязка к смежным системам (`extNum`, `extLink`), дедлайны.
- 🔄 **Изменения (CR / Баги / Фичи)**: Журнал доработок в рамках задач с конвертацией и связыванием.
- 👥 **Сотрудники**: Разделение ролей (**Разработчик** / **Агент / ПМ / Аналитик**), признак активности (архивация).
- 🏷 **Справочники**: Заказчики, приоритеты с весовыми коэффициентами, статусы задач и проектов, этапы разработки.

### 3. Представления данных
- **Таблица**:
  - Многоуровневая группировка (до 2 уровней) со сворачиванием/разворачиванием групп и подсчетом количества.
  - Встроенные фильтры в заголовках колонок (`<th>`) со всплывающими окнами поиска и алфавитной сортировкой (отображаются только фактически присутствующие в строках значения).
  - Сортировка, drag-and-drop перемещение колонок, настройка видимости и ширины полей.
  - Индикатор применённых фильтров с кнопкой мгновенного сброса.
- **Канбан-доска**:
  - Drag & Drop перемещение карточек между статусами, этапами или исполнителями.
  - Компактный поповер фильтрации (по статусам, этапам, разработчикам, агентам, заказчикам) и индикатор сброса.
  - Создание кастомных досок с настройкой колонок, цветовых схем и лимитов WIP (Work In Progress).
- **Таймлайн (Диаграмма Ганта)**:
  - Визуализация сроков (`start` / `end`) по дням, месяцам, кварталам и годам.
  - Группировка по статусам, этапам, разработчикам, агентам и приоритетам (отображение только активных сотрудников).
  - Сохранение кэшированной позиции прокрутки без навязчивого скролла к сегодняшнему дню.
  - Компактный поповер фильтрации и бейдж активных фильтров.
  - Интерактивное перетаскивание и растягивание сроков полос.
- **Отчёты и дашборды Power BI**:
  - Интерактивные срезы (по статусам, приоритетам, заказчикам, разработчикам, агентам, датам).
  - Настраиваемый дашборд с перемещением и скрытием аналитических блоков.
  - График общей динамики этапов проектов в разрезе периодов (день/месяц/квартал/год).
- **Журнал изменения этапов**:
  - Хронологическая фиксация динамики прогресса с расчетом дельты (`+X%` / `-Y%`).
  - Интерактивные мини-графики (Sparklines) по каждому этапу в карточке просмотра проекта с разрезами периодов (Год / Квартал / Месяц / День).
- **Инспектор БД**:
  - Чистый табличный просмотр всех системных таблиц SQLite без визуального шума.
  - Отображение первичных ключей (`id`), внешних ключей, дат и JSON-полей.
  - Встроенная полнофункциональная SQL-консоль с поддержкой чтения (`SELECT`) и модификации данных (`INSERT`, `UPDATE`, `DELETE`, `CREATE`), историей и готовыми шаблонами запросов.
- **Единая компактная верхняя панель (Unified Topbar)**:
  - Интеграция названия модуля, счетчика записей, быстрого поиска, кнопок создания, шаблонов импорта и переключателя представлений в одну строку для максимальной экономии полезного пространства.
- **Журнал аудита**:
  - Аудит безопасности, фиксация IP-адресов, действий, измененных полей и User-Agent.
  - Быстрый переход на объект по клику в журнале.

### 4. Карточка объекта и инструменты
- **Чек-листы и Заметки**: Интерактивные чек-листы с прогресс-баром и журнал заметок с автором и датой.
- **Прогресс по этапам**: Ползунки с общими кнопками **[Применить]** и **[Отменить]** для пакетного сохранения.
- **Интерактивный конструктор форм**: Настройка порядка и видимости полей прямо из интерфейса.
- **Современная эстетика**: Чистый интерфейс с контурными линейными SVG-иконками (без смайликов) и шрифтом JetBrains Mono.

## 🛠 Технологический стек

- **Backend**: Python 3.10+, `aiohttp`, `aiosqlite`, `sqlite3`, `PyInstaller`.
- **Frontend**: Чистый JavaScript (ES Modules, ES2022+), HTML5 Semantic, Vanilla CSS.
- **Хранилище**: SQLite 3 (WAL mode) + клиентский IndexedDB кэш.
- **Сетевой уровень**: REST API (`/api/*`) + WebSocket (`/ws`) для реактивной синхронизации.
- **Иконки & Шрифты**: Linear Outline SVG, Inter, Unbounded, JetBrains Mono.

## 🚀 Запуск и установка

### Вариант 1: Готовый исполняемый файл (Windows)
1. Запустите файл `dist/ProjectsSPA.exe`.
2. Сервер автоматически запустится на порту `3000` и откроет страницу в браузере по умолчанию.

### Вариант 2: Запуск из исходного кода (Python)
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/kutya001/Projects.git
   cd Projects
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сервер:
   ```bash
   python server.py
   ```
4. Откройте в браузере: `http://localhost:3000`

## 📦 Сборка дистрибутива (PyInstaller)

Для сборки проекта в один `.exe` файл:
```bash
py -3 -m PyInstaller ProjectsSPA.spec --noconfirm
```
Собранный исполняемый файл будет находиться в директории `dist/ProjectsSPA.exe`.
